Méthode de classification

Règles de classification BIO

Les données proviennent en direct de l'ERP Odoo (base de production) : réceptions fournisseurs validées (transferts entrants terminés) et ordres de fabrication terminés, avec leurs numéros de lots.

Un enregistrement est classé BIO si au moins un critère est rempli :

• le numéro de lot porte le marquage bio : suffixe …-B ou mention BIO dans le numéro ;
• le nom du produit contient « bio » ;
• pour une fabrication : la case « Forcer lots BIO » est cochée sur l'ordre de fabrication.

Pour chaque fabrication bio, la liste complète des intrants consommés (produit, n° de lot, quantité) est affichée. Les intrants dont le lot ne porte pas le marquage bio sont signalés en rouge ; les emballages (bocaux, bouteilles, capsules, cartons, étiquettes) sont identifiés à part car non concernés par la certification des ingrédients.

Le badge du critère est affiché sur chaque ligne : LOT = marquage sur le lot, NOM = « bio » dans le nom du produit, FORCÉ = marquage manuel sur l'OF.

Chaque fabrication est rattachée à une étape d'après la catégorie Odoo du produit fabriqué : PRÉPARÉ (catégories « Fruits/Légumes préparés » — la transformation du brut), CUISSON (catégories « ◦ Cuisson / Assemblage », fermentation) et FINI (catégories « ◦ Empotage », « ◦ Produits finis », produits clients — le produit conditionné). Si le produit n'a pas de catégorie, l'étape est déduite du nom (contenance type « 314mL » → fini, « préparé / purée / jus » → préparé…).

L'onglet Traçabilité lot reconstruit la généalogie complète d'un lot à partir de l'ensemble des mouvements Odoo (toutes les réceptions, fabrications et livraisons, bio ou non) : en amont, la chaîne remonte du lot vers les fabrications qui l'ont produit puis les lots consommés et leurs réceptions fournisseur ; en aval, elle descend vers les fabrications qui ont consommé le lot (produit préparé → produit fini) jusqu'aux livraisons clients. Tous les numéros de lot affichés dans l'app sont cliquables et ouvrent leur généalogie.
